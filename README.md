# Amazon Sales Data Analysis 📊

## Project Overview
This project performs **Exploratory Data Analysis (EDA)** on an Amazon Sales dataset to uncover insights related to **pricing behavior, discounts, product ratings, and customer engagement**.

The project was executed using *Python* and follows a structured data analytics workflow similar to real-world business analysis.

## Objectives
- Analyze product pricing and discount patterns
- Study the relationship between discounts and product ratings
- Identify outliers in product prices
- Understand customer engagement through rating counts
- Present insights using clear visualizations

## Tools & Technologies
- **Python**
- **Pandas, NumPy** – Data cleaning & manipulation
- **Matplotlib, Seaborn** – Data visualization
- **VS Code** – Development environment
